# SIAR — Sistema Integral de Administración para Restaurantes

Proyecto de semestre para la asignatura Ingeniería de Software.

## Descripción

Aplicación web para gestionar la operación de un restaurante
pequeño o mediano: usuarios, menú, pedidos, inventario,
facturación y reservas.

## Stack tecnológico

- **Lenguaje:** TypeScript
- **Frontend:** React + Bootstrap 5
- **Backend:** Node.js 20 + Express 4 + TypeScript
- **Base de datos:** PostgreSQL 15
- **Control de versiones:** Git + GitHub
- **IDE:** Visual Studio Code
